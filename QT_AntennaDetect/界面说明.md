# QT天线检测系统界面说明

## 界面布局

### 整体尺寸
- 宽度：1024像素
- 高度：748像素

### 左侧区域（图像显示和控制）
1. **图像显示区域**
   - 占据左侧大部分空间
   - 使用ScrollArea支持滚动查看大图
   - 自动缩放保持图像比例
   - 灰色背景边框

2. **控制按钮区域**
   - 开始检测：启动实时检测（待实现YOLO集成）
   - 停止检测：停止当前检测
   - 加载图片：从本地选择图片文件
   - 保存图片：保存处理后的图片

### 右侧区域（图像处理控制面板）
宽度固定为350像素

1. **滤镜效果**
   - 灰度化：将彩色图像转为灰度
   - 模糊：应用高斯模糊滤镜
   - 边缘检测：使用Canny算法检测边缘

2. **图像调整**
   - 亮度调整：-100到100的滑块控制
   - 对比度调整：-100到100的滑块控制
   - 实时显示当前数值

3. **应用处理按钮**
   - 应用所有选中的图像处理效果
   - 橙色高亮显示

4. **处理后预览**
   - 300x150像素的预览窗口
   - 实时显示处理效果
   - 保持图像比例

5. **结果信息**
   - 文本框显示详细处理信息
   - 包括图像参数和处理状态
   - 固定高度150像素

### 底部状态栏
- 显示当前系统状态
- 居中显示
- 灰色背景

## 主要功能

### 图像加载
- 支持格式：JPG, JPEG, PNG, BMP, TIFF
- 自动显示图像信息
- 启用所有处理控件

### 实时处理
- 滑块调整时实时更新
- 复选框切换即时生效
- 自动更新主图像和预览

### 图像处理效果
1. **灰度化**
   - 转换为灰度图像
   - 保持3通道格式

2. **模糊**
   - 5x5高斯模糊
   - 平滑处理

3. **边缘检测**
   - Canny算法
   - 阈值：50-150

4. **亮度和对比度**
   - 亮度范围：-100到100
   - 对比度范围：-100到100
   - 公式：output = input × α + β
   - α = 1 + (对比度/100)
   - β = 亮度值

### 保存功能
- 支持JPG、PNG、BMP格式
- 自动转换格式
- 显示保存成功/失败提示

## 使用流程

1. **启动程序**
   - 运行QT_AntennaDetect.exe
   - 界面加载完成

2. **加载图片**
   - 点击"加载图片"按钮
   - 选择本地图片文件
   - 图像自动显示在左侧区域

3. **调整效果**
   - 勾选需要的滤镜效果
   - 拖动滑块调整亮度和对比度
   - 实时查看效果

4. **应用处理**
   - 点击"应用处理"按钮确认所有效果
   - 处理时间显示在状态栏
   - 结果信息更新在右侧面板

5. **保存结果**
   - 点击"保存图片"按钮
   - 选择保存路径和格式
   - 完成保存
