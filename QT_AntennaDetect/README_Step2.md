# Qt 天线检测系统 - 第二步：OpenCV 图像处理

## 概述
本版本集成了 OpenCV 图像处理功能，支持基本的图像操作和处理。

## 新增功能

### 1. 图像加载
- 支持 JPG、JPEG、PNG、BMP、TIFF 格式
- 自动显示图像信息（尺寸、通道数等）
- 图像缩放适应显示区域

### 2. 图像处理功能
#### 滤镜效果
- **灰度转换**: 将彩色图像转换为灰度图像
- **模糊处理**: 使用高斯模糊平滑图像
- **边缘检测**: 使用 Canny 算子检测图像边缘

#### 图像调整
- **亮度调整**: -100 到 +100 范围内调整
- **对比度调整**: -100 到 +100 范围内调整

### 3. 图像保存
- 支持保存为 JPG、JPEG、PNG、BMP 格式
- 自动选择适当的压缩质量

## 界面说明

### 左侧区域
- 图像显示区域：显示原始图像和处理后的图像
- 控制按钮：开始检测、停止检测、加载图片、保存图片
- 状态栏：显示当前状态和处理信息

### 右侧区域 - 图像处理控制面板
- **滤镜效果**：可以选择应用灰度、模糊、边缘检测
- **图像调整**：使用滑块调整亮度和对比度
- **应用处理**按钮：实时应用所有选中的效果
- **处理后的图片预览**：小窗口显示处理效果
- **结果信息**：显示图像信息和处理状态

## 使用方法

### 1. 编译项目
```bash
# 使用交叉编译器
/home/topeet/Linux/rk356x_linux/buildroot/output/rockchip_rk3568/host/bin/qmake QT_AntennaDetect_Step2.pro
make
```

### 2. 运行程序
```bash
./QT_AntennaDetect_Step2
```

### 3. 使用步骤
1. 点击"加载图片"选择图像文件
2. 在右侧控制面板选择需要的处理效果
3. 调整亮度和对比度滑块
4. 点击"应用处理"查看效果
5. 满意后点击"保存图片"保存结果

## OpenCV 配置要求

### 库文件结构
```
3rdparty/opencv/
├── include/          # OpenCV 头文件
│   ├── opencv2/
│   │   ├── core.hpp
│   │   ├── highgui.hpp
│   │   ├── imgproc.hpp
│   │   └── imgcodecs.hpp
│   └── opencv.hpp
└── lib/              # OpenCV 库文件
    ├── libopencv_core.so.4.5.0
    ├── libopencv_highgui.so.4.5.0
    ├── libopencv_imgproc.so.4.5.0
    └── libopencv_imgcodecs.so.4.5.0
```

### 依赖库
- OpenCV 4.x 版本
- Qt 5.8.0
- RK3568 交叉编译环境

## 常见问题

### 1. 编译错误：找不到 OpenCV 头文件
**解决方案**：检查 3rdparty/opencv/include 路径是否正确

### 2. 运行错误：无法加载 OpenCV 库
**解决方案**：检查 LD_LIBRARY_PATH 环境变量是否包含 OpenCV 库路径

### 3. 图像处理慢
**解决方案**：减小图像尺寸或优化处理算法
