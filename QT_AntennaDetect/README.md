# QT 天线检测系统集成项目

基于RK3568平台的YOLO天线检测系统，集成USB相机和图像处理功能。

## 系统要求
- 目标平台：RK3568 (Linux)
- 开发环境：Linux 虚拟机
- Qt 版本：5.8.0
- 依赖库：OpenCV、RKNN API、RGA、海康威视相机 SDK

## 编译说明

### 1. 准备依赖库
确保以下目录存在且包含必要的文件：
```
../lib/                    # 库文件目录
../3rdparty/opencv/        # OpenCV 库
../3rdparty/libhikvision/  # 海康威视相机 SDK
../yolov8_model/          # YOLO 模型文件
```

### 2. 模型文件准备
将以下文件放到相应目录：
- `../yolov8_model/best.rknn` - YOLO 模型文件
- `../yolov8_model/antenna.txt` - 标签文件

### 3. 编译命令
```bash
# 清理之前的编译
rm -f Makefile *.o

# 生成 Makefile
/home/topeet/Linux/rk356x_linux/buildroot/output/rockchip_rk3568/host/bin/qmake -o Makefile QT_AntennaDetect.pro

# 编译
make
```

## 使用方法

### 启动程序
```bash
./QT_AntennaDetect
```

### 功能说明

#### 1. YOLO模型加载
- 点击"加载模型"按钮
- 选择RKNN格式的YOLO模型文件
- 选择对应的标签文件（.txt格式）
- 模型加载成功后，YOLO检测按钮变为可用状态

#### 2. 图片检测
- 点击"加载图片"按钮
- 选择本地图片文件（支持 jpg、jpeg、png、bmp）
- 可选择图像处理效果（灰度化、模糊、边缘检测）
- 调整亮度和对比度
- 点击"YOLO检测"按钮进行检测
- 检测结果显示在右侧面板中

#### 3. 实时检测
- 点击"开始检测"按钮
- 系统启动USB相机并开始实时检测
- 检测结果实时显示在界面上
- 点击"停止检测"按钮结束

#### 4. 图像处理
- 使用右侧控制面板的复选框选择图像处理效果
- 调整亮度滑块（-100到100）
- 调整对比度滑块（-100到100）
- 点击"应用处理"按钮应用所有效果

#### 5. 状态显示
- 顶部状态栏显示当前系统状态
- 右侧面板显示检测结果和性能统计
- 底部文本框显示系统功能说明和使用步骤

## 注意事项

1. **模型文件**
   - 确保 YOLO 模型文件路径正确
   - 模型输入尺寸为 640x640

2. **相机配置**
   - 当前使用海康威视相机
   - 确保相机已正确连接
   - 可能需要调整相机索引

3. **权限问题**
   - 确保程序有访问相机的权限
   - 可能需要使用 sudo 运行

4. **性能优化**
   - 使用 RGA 硬件加速
   - DMA 内存减少数据拷贝

## 故障排除

### 1. 编译错误
- 检查依赖库路径是否正确
- 确保所有头文件存在

### 2. 运行错误
- 确保模型文件存在
- 检查相机连接状态

### 3. 检测失败
- 检查输入图片格式
- 确认模型训练的类别
