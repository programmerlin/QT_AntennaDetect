## 编译建议

1. **先测试基本界面**
   ```bash
   mv QT_AntennaDetect.pro QT_AntennaDetect_Backup.pro
   cp QT_AntennaDetect_Simple.pro QT_AntennaDetect.pro
   qmake && make
   ```

2. **逐步添加功能**
   - 每次只添加一个模块
   - 确保每次编译成功
   - 使用 git 记录每次修改

3. **处理依赖关系**
   - RKNN API 需要在 RK3568 系统中
   - OpenCV 需要交叉编译版本
   - 相机 SDK 需要正确安装

## 注意事项

1. **交叉编译环境**
   - 确保所有库都是为 aarch64 交叉编译的
   - 库文件路径需要正确

2. **文件权限**
   - 确保所有源文件都有读取权限
   - 模型文件需要有执行权限

3. **内存管理**
   - DMA 内存需要特殊处理
   - 避免内存泄漏
