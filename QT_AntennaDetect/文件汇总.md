# 项目文件汇总

## 项目概述
这是一个基于 YOLO 的天线检测系统，使用 Qt 5.8.0 作为界面框架。

## 文件结构

### 1. QT_AntennaDetect/ - Qt 项目主目录
```
QT_AntennaDetect/
├── main.cpp              - Qt 主程序入口
├── widget.h              - Qt 主窗口头文件
├── widget.cpp            - Qt 主窗口实现
├── widget.ui             - Qt 界面设计文件
├── QT_AntennaDetect.pro  - Qt 项目配置文件
├── plan.md              - 项目实施计划
├── README.md            - 使用说明
└── 文件汇总.md          - 本文件
```

### 2. 核心组件文件

#### Antenna_Visioner/ - 天线视觉检测模块
```
Antenna_Visioner/
├── include/
│   ├── Antenna_Visioner.h  - 主头文件
│   ├── yolov8.h           - YOLOv8 模型接口
```

## 重要文件说明

### 1. 模型文件
- `./yolov8_model/best.rknn` - YOLO 模型文件（RKNN 格式）
- `./yolov8_model/antenna.txt` - 标签文件

### 2. 主要功能
1. **图像采集** - 通过海康威视相机采集图像
2. **YOLO 推理** - 使用 RKNN 加速的 YOLO 模型进行目标检测
3. **结果显示** - 在 Qt 界面显示检测结果
4. **RGA 加速** - 使用 Rockchip RGA 进行图像处理

### 3. 编译依赖
- Qt 5.8.0
- OpenCV
- RKNN API
- RGA 库
- 海康威视相机 SDK
